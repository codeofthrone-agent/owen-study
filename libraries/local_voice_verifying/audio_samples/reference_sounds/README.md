# 參考聲音檔案目錄

這個目錄用來存放聲音檢測所需的參考音訊檔案。

## 使用說明

1. 將目標聲音的音訊檔案放置在此目錄下
2. 檔案命名應與要檢測的聲音名稱相同
3. 支援的音訊格式：WAV, MP3, M4A

## 範例檔案命名

```
登登.wav          # 檢測 "登登" 聲音時使用
beep.wav          # 檢測 "beep" 聲音時使用
notification.wav  # 檢測 "notification" 聲音時使用
alarm.mp3         # 檢測 "alarm" 聲音時使用
```

## 音訊品質建議

- 取樣率: 16kHz 或更高
- 位元深度: 16-bit
- 聲道: 單聲道 (系統會自動轉換立體聲)
- 長度: 1-5 秒
- 背景噪音: 越少越好
- 音量: 適中，避免過大或過小

## 錄製建議

1. **環境**: 安靜的環境，減少背景噪音
2. **距離**: 麥克風距離聲源 10-30 公分
3. **多樣本**: 可以錄製同一聲音的多個版本以提高檢測準確率
4. **格式**: 建議使用 WAV 格式以獲得最佳品質

## 自動載入

系統會自動嘗試載入以下檔案（按優先順序）：
1. `{聲音名稱}.wav`
2. `{聲音名稱}.mp3`
3. `{聲音名稱}.m4a`

例如，檢測 "登登" 聲音時，系統會依序尋找：
- 登登.wav
- 登登.mp3
- 登登.m4a

## 注意事項

- 參考聲音的品質直接影響檢測準確率
- 建議定期更新參考聲音以維持檢測效果
- 如果檢測效果不佳，可以嘗試調整參考聲音或檢測閾值
